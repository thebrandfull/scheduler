## 📱 Technical Approach

### AI Context Management
Store in Supabase:
```sql
CREATE TABLE ai_context (
  user_id UUID,
  context_type TEXT, -- 'daily_briefing', 'progress_analysis', etc.
  context_data JSONB,
  last_updated TIMESTAMPTZ,
  embeddings VECTOR(1536) -- for semantic search if needed
);
```

### DeepSeek API Usage
```javascript
// Morning Briefing
const briefing = await deepseek.chat({
  messages: [
    { role: 'system', content: 'You are a motivational fitness coach...' },
    { role: 'user', content: `
      User Stats:
      - Day: 23/102
      - Streak: 7 days
      - Last week completion: 32/35 tasks
      - Current weight: 79kg (started 85kg)

      Generate a morning briefing.
    `}
  ]
});
```

### Caching Strategy
- Cache AI responses for 24hrs (morning briefing)
- Cache insights for 7 days (weekly analysis)
- Real-time for chat
- Background generation for predictions
